# Speed Jump System

Enhance your FiveM experience with customizable speed and jump abilities.

## Features

- Toggleable speed boost
- Toggleable super jump
- Persistent settings across sessions

## Requirements

- FiveM server with ESX framework
- MySQL database

## Installation

1. Download the script files
2. Place them in your server's resources folder
3. Add `start speedjumpsystem` to your server.cfg
4. Import the database.sql file into your MySQL database

## Usage

- Press the configured key (default: E) to toggle between speed and jump abilities

## Configuration

Edit the `config.lua` file to customize:

- Speed multiplier and duration
- Jump multiplier and duration
- Toggle key
- Database table name
